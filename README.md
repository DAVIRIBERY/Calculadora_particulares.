# Calculadora de Percentual — Orçamento x Sistema MV

## Sobre o projeto

Aplicação desenvolvida em Python com o objetivo de calcular a relação percentual entre o valor de um orçamento e o valor informado para o sistema MV.

O programa recebe dois valores financeiros digitados pelo usuário e utiliza uma função matemática para realizar o cálculo percentual, apresentando o resultado com duas casas decimais.

## Funcionalidades

- **Entrada do orçamento:** solicita ao usuário o valor total do orçamento.
- **Entrada do sistema MV:** recebe o valor correspondente ao sistema MV.
- **Cálculo percentual:** realiza a operação matemática para identificar a relação percentual entre os dois valores.
- **Exibição do resultado:** apresenta o percentual calculado com duas casas decimais.
- **Execução contínua:** utiliza uma estrutura de repetição `while True`, permitindo realizar novos cálculos sem reiniciar o programa.

## Fórmula utilizada

O programa utiliza a seguinte fórmula:

Percentual = (Valor do orçamento × 100) / Valor do sistema MV

## Tecnologias e conceitos utilizados

- **Python:** linguagem utilizada no desenvolvimento.
- **Funções (`def`):** organização e reutilização de código.
- **`input()`:** captura de informações fornecidas pelo usuário.
- **`float()`:** conversão dos valores informados para números decimais.
- **`return`:** retorno dos resultados das funções.
- **Operadores matemáticos:** multiplicação e divisão.
- **`while True`:** estrutura de repetição contínua.
- **F-strings:** formatação e apresentação dos resultados.
- **`:.2f`:** exibição
